# Banyan 桌面 Agent 工作台 · 界面设计方案 v1.0

> 作者：Banyan
> 定位：基于 `pi-agent-core` 的本地编码 Agent 工作台（Electron + React 19 + Tailwind v4）
> 本方案在现有 M1 骨架（项目 → 会话 → 对话 + 改动 / 设置）基础上做信息架构与视觉的收敛与升级。

---

## 1. 产品定位与设计原则

### 1.1 一句话定位
> **一个"窗口"里完成编码 Agent 的全部闭环：给它项目、看它干活、批它动刀、追溯它改了什么。**

Banyan 不是聊天软件，是**操作台**。用户心态是"监工 + 授权者"：我委托一件工作，Agent 执行，我随时可介入、可回滚、可审计。

### 1.2 六条设计原则

| 原则 | 含义 | 界面体现 |
|---|---|---|
| **过程可观测** | Agent 的每一步（思考/调用工具/改文件）都要可见，不能黑盒 | 工具调用内联在消息流中、运行中的终端输出实时回写 |
| **权限显性化** | 当前是"审批模式"还是"全权执行"，必须一眼可见且不易误触 | 顶栏持久化模式徽章，危险态换暖色 |
| **一切可追溯** | 谁改的、什么时候、改了什么，随时可查可回滚 | 改动/用量/工具/分支四个侧面板 + 项目级改动汇总 |
| **干脏活时聚焦** | 对话为主轴，辅助信息按需展开，不抢注意力 | 右侧面板"多选一抽屉"，默认收起 |
| **本地优先** | 数据在本地、密钥在本地、路径暴露给用户 | 顶部显式展示 cwd，设置页显式展示数据目录 |
| **键盘优先** | 高频操作不离开键盘 | 全局快捷键、Enter 发送、Esc 关闭面板/中断 |

## 2. 信息架构

### 2.1 三层对象模型（与后端协议一一对应）

```
Project（项目 = 一个本地目录 rootPath）
  └── Session（会话 = 一条对话任务线，JSONL 持久化）
        ├── Messages（消息流：user / assistant / tool）
        ├── BranchTree（分支树：可导航、可回溯的编辑历史）
        ├── ToolCalls / Usage / FileChanges（三本审计账）
        └── RunState（idle / running）
```

### 2.2 布局总览（三栏 + 顶栏）

```
┌──────────────────────────────────────────────────────────────────────────┐
│ 顶栏  Banyan │  [项目路径]        [会话|改动|设置]   [审批模式徽章] [设置] │  44px
├────────────┬──────────────────────────────────────────┬──────────────────┤
│            │  会话头：cwd · 模型选择 · tokens/成本      │                  │
│  导航栏     │           · 上下文占用 · 面板开关          │  右侧抽屉         │
│  256px     ├──────────────────────────────────────────┤  320px（按需）    │
│            │                                          │                  │
│ 项目列表    │            消息流（max-w-3xl 居中）         │  改动 / 分支      │
│ ─────────  │      user / assistant / tool / 运行中工具  │  用量 / 工具      │
│ 会话列表    │            审批卡片（阻塞在末尾）           │                  │
│            │                                          │                  │
│            ├──────────────────────────────────────────┤                  │
│            │  输入区：textarea + 发送 / 插话 / 中断       │                  │
└────────────┴──────────────────────────────────────────┴──────────────────┘
```

**尺寸规范**：顶栏 44px · 导航栏 256px · 右侧抽屉 320px · 正文列宽上限 768px（`max-w-3xl`）· 基础间距 4px 栅格 · 圆角 6px（控件）/ 8px（卡片）。

## 3. 逐区域设计

### 3.1 顶栏（Top Bar）

```
┌───────────────────────────────────────────────────────────────────┐
│ 🌳 Banyan  桌面 Agent 工作台   │ E:\code\my-app   [会话][改动][设置]  ⬤ 审批模式  ⚙ │
└───────────────────────────────────────────────────────────────────┘
```

**左区**：品牌名 + 定位副标；打开项目后追加**当前项目路径**（等宽字体、可点击复制、hover 显示完整路径）。

**中区**：三视图分段控件（Segmented Control）——`会话 / 改动 / 设置`，激活项用 `surface-overlay` 底色。

**右区**：
- **审批模式徽章**（核心安全控件）：
  - `审批模式` → 蓝色 `ShieldCheck`，语义"动刀前先问我"
  - `全权执行模式` → 琥珀色 `ShieldAlert` + 轻微脉冲提示，语义"Agent 可任意操作"
  - 点击切换，切换为全权时弹出一次确认气泡（防误触）
- **环境告警位**：`env.bashPath` 缺失时显示红色 `⚠ 未找到 bash，命令工具不可用`
- **设置齿轮**：进入设置页

> 改进点：把现有"设置"从分段控件里剥出来单独做齿轮，避免安全徽章和导航挤在一起产生误点；全权模式增加颜色+动效双重强调。

### 3.2 导航栏（左侧 256px）

上下两段，可拖拽分隔（记忆比例）：

**上段 · 项目**
```
项目                                    [＋ 打开]
▸ banyan                    E:\code\opensource\banyan   ← 激活
  workmate-api              D:\work\workmate-api
```
- 每项两行：名称（primary）/ 路径（muted，截断）
- 激活项左侧 3px 强调色竖条 + `surface-overlay` 底
- 支持最近项目排序（`lastOpenedAt`），未打开任何项目时空态引导

**下段 · 会话**
```
会话                                    [＋ 新建]
● 修复登录超时 bug           5 分钟前 · 12 条
  首次接入 DeepSeek          昨天 · 3 条
```
- 每条：标题（首条 user 消息截断 30 字）/ 更新时间 · 消息数
- `running` 会话显示呼吸绿点，方便切换回来
- 右键菜单：重命名 / 归档 / 删除

**空态**：无项目 → "还没有项目，点『打开』选择目录"；有项目无会话 → "还没有会话，点『新建』开始"。

### 3.3 会话主区

#### 3.3.1 会话头（Session Header）
```
E:\code\opensource\banyan                          [压缩上下文] [分支][改动 3][用量][工具] [■中断]
deepseek-chat   12,430 tokens · $0.0021 · 上下文 38.2%
```
- 左：cwd + 模型选择器（多 provider 时 `optgroup` 分组下拉）+ token/成本/上下文占用
- 右：上下文 >70% 时出现琥珀色"压缩上下文"；面板开关一组；运行时显示红色"中断"
- **上下文占用**建议升级为**细进度条**（当前是纯文本百分比），>70% 变琥珀、>90% 变红

#### 3.3.2 消息流
- 列宽 `max-w-3xl` 居中，`gap-16px`
- **User**：右对齐或左侧带色块，简洁
- **Assistant**：左对齐，Markdown 渲染 + 代码块（带复制/语言标签）
- **Tool 调用卡片**：内联在流中，可折叠
  - 头部：工具图标 + `font-mono` 工具名 + 状态点（运行中 spinner / 成功绿 / 失败红）+ 耗时
  - 展开：入参 JSON（高亮）+ 终端输出（`TerminalOutput`，等宽）
  - bash 类工具运行中持续回写全量快照，`max-h-72` 可滚动
- **流式文本**：assistant 逐字 + 末尾光标闪烁
- **审批卡片**：阻塞在消息流末尾（Agent 真的卡在这里），不处理不继续

#### 3.3.3 输入区
```
┌────────────────────────────────────────────────┐
│ 输入消息，Enter 发送，Shift+Enter 换行            │  ← 运行中改为"输入内容将作为插话…"
└────────────────────────────────────────────────┘        [发送 ➤]
队列中还有 2 条待处理
```
- 运行中发送 → 作为**插话（steer）**，输入框占位提示随之改变
- 有队列积压时底部提示条

### 3.4 右侧抽屉（Side Panel · 320px，多选一）

四个面板互斥，点击头部开关展开/收起，`Esc` 关闭：

| 面板 | 内容 | 核心价值 |
|---|---|---|
| **改动 Changes** | 本次会话 `fileChanges`，按文件分组，`DiffView` 红绿对比，+/− 行数 | 看它改了什么、审阅 |
| **分支 Branches** | `BranchTree` 树形，标 `onActivePath` / `isTip`，点节点 `navigate` | 回到任意历史节点重新分叉 |
| **用量 Usage** | 每次模型调用记录 + 累计（input/output/cache/cost/calls） | 成本可审计 |
| **工具 Tools** | 按 `runId` 聚合的工具调用历史，成功/失败、耗时 | 排查哪步出了问题 |

> 抽屉与消息流可并存，窄屏（<1200px）时抽屉改为**浮层**覆盖，避免挤压正文。

### 3.5 改动视图（项目级）

跨会话的项目改动汇总（`changes.list`）：
- 顶部统计卡：X 个文件 · +N / −M 行
- 列表按会话归属分组，每项显示文件路径、改动类型、增删行数
- 点击展开 patch diff
- 支持按会话 / 文件 / 时间筛选

### 3.6 设置视图
分区块（Section）：
1. **模型 Provider** — 内置 DeepSeek + 自定义 OpenAI 兼容；每项展示名称、baseUrl、模型列表、密钥状态（掩码）、可否删除（builtin 锁）
2. **密钥** — DeepSeek API Key 录入（`secrets.set`，绝不回显明文，仅显示掩码）
3. **审批策略** — 默认模式、同类签名免问、按工具免问的白名单管理
4. **环境信息** — Electron/Node/Chrome 版本、node:sqlite 可用性、bash 路径与来源
5. **数据与隐私** — 用户数据目录（可打开/复制）、会话 JSONL 位置、清空数据入口（二次确认）

### 3.7 首次运行引导（FirstRunGate · 全屏模态）
- 检测到历史数据（`hasHistoricalData`）时弹出：
  - 展示发现的项目数 / 会话数 / 是否已配置密钥
  - 两个明确选项：**沿用历史数据（import）** / **清空重来（fresh，危险色 + 二次确认）**
- 无历史数据时跳过，直接进主界面

### 3.8 审批卡片（安全关键组件）
```
┌───────────────────────────────────────────────┐
│ ⚠ 危险操作 · 写入文件                          │
│ 工具：write  →  E:\code\my-app\src\auth.ts     │
│ 判定依据：覆盖已有文件，可能丢失未提交改动        │
│ ┌───────────────────────────────────────────┐ │
│ │ 入参 JSON（可折叠）                         │ │
│ └───────────────────────────────────────────┘ │
│ [拒绝]                    [本次允许] [记住此类] │
└───────────────────────────────────────────────┘
```
- 风险档位配色：`safe` 蓝 / `moderate` 琥珀 / `dangerous` 红
- 拒绝可填原因回传模型
- "记住"两档：仅同签名免问（signature）/ 整个工具免问（tool）

## 4. 视觉系统

### 4.1 色板（沿用并微调现有 @theme）

| Token | 值 | 用途 |
|---|---|---|
| `surface` | `#0b0d10` | 应用底色 |
| `surface-raised` | `#12151a` | 导航栏、卡片 |
| `surface-overlay` | `#171b22` | 激活态、悬浮 |
| `border-subtle` | `#232931` | 分隔线、描边 |
| `text-primary` | `#e6e9ef` | 正文 |
| `text-secondary` | `#98a2b3` | 次级文字 |
| `text-muted` | `#6b7480` | 占位、时间戳 |
| `accent` | `#4f9cf9` | 主操作、激活、审批模式 |
| `success` | `#3fb950` | 成功、运行中 |
| `warning` | `#d29922` | 警告、全权模式、上下文告警 |
| `danger` | `#f85149` | 危险操作、错误、中断 |

暗色为主基调（开发者工具观感）。**无障碍**：正文对底色对比度 ≥ 7:1；状态色不与颜色单一绑定，均配图标或文字。

### 4.2 字体与排版
- 中文 UI：`Microsoft YaHei UI / Segoe UI / system-ui`
- 等宽（路径、工具名、代码、输出）：`Cascadia Code / Consolas / ui-monospace`
- 字阶：11 / 12 / 13 / 14（正文）/ 16 / 20。行高 1.5，代码块 1.6

### 4.3 间距与圆角
- 4px 基线栅格；区块内边距 8/12/16px；面板间距 12px
- 圆角：控件 6px，卡片 8px，徽章 pill

### 4.4 图标
`lucide-react` 统一 12/14px（内联）/ 16px（按钮）。语义映射：`MessageSquare` 会话、`FileDiff` 改动、`GitBranch` 分支、`Coins` 用量、`Wrench` 工具、`ShieldCheck/ShieldAlert` 审批。

## 5. 关键交互与快捷键

| 快捷键 | 行为 |
|---|---|
| `Enter` | 发送消息 / 运行中作为插话 |
| `Shift + Enter` | 换行 |
| `Esc` | 关闭右侧抽屉；阻塞态下触发中断确认 |
| `Ctrl + N` | 新建会话 |
| `Ctrl + O` | 打开项目 |
| `Ctrl + K` | 命令面板（跳项目 / 会话 / 视图 / 切模型） |
| `Ctrl + /` | 快捷键帮助 |

**状态反馈**：
- `session.status` → 导航栏绿点 + 会话头"中断"按钮出现
- `approval.pending` → 卡片插入消息流末尾 + 自动滚底 + 顶栏/任务栏徽标计数
- `session.error` → 消息流顶部红色条（可关闭），不打断输入

## 6. 空态、加载态、错误态

| 场景 | 设计 |
|---|---|
| 未选项目 | 全屏居中：插画 + "打开一个项目目录开始" + 主按钮 |
| 无会话 | "新建一个会话开始对话" + 主按钮 |
| 会话启动中 | 顶部 `Loader2` 旋转 + "正在启动会话进程…" |
| 无密钥 | 琥珀告警条 + 直达设置 |
| 无 bash | 顶栏红色告警 |
| 无消息 | 居中"会话已就绪，输入你的第一个问题。" |
| 工具失败 | 工具卡片红色状态点 + 输出可展开 |

## 7. 响应式断点

| 宽度 | 行为 |
|---|---|
| ≥ 1440 | 三栏全展开，右抽屉常驻 |
| 1200–1440 | 导航栏可折叠为图标条 |
| < 1200 | 右抽屉转为浮层覆盖；导航栏抽屉化（汉堡唤起） |
| < 900 | 单栏，视图切换用底部分段控件 |

## 8. 与现有实现的差异清单（落地建议）

| # | 现状 | 建议 | 优先级 |
|---|---|---|---|
| 1 | "设置"在顶栏分段控件内，与审批徽章相邻 | 设置移到右侧齿轮，降低误触 | P0 |
| 2 | 全权模式仅靠颜色区分 | 增加切换确认气泡 + 徽章脉冲动效 | P0 |
| 3 | 上下文占用是纯文本百分比 | 改为细进度条，分级变色 | P1 |
| 4 | 无命令面板 | 增加 `Ctrl+K` 命令面板 | P1 |
| 5 | 会话列表无状态点 | running 会话显示呼吸绿点 | P1 |
| 6 | 项目/会话列表无右键菜单 | 增加重命名/归档/删除 | P2 |
| 7 | 抽屉挤压正文 | 窄屏改浮层 | P2 |
| 8 | 侧栏不可调宽 | 支持拖拽 + 记忆比例 | P2 |

## 9. 里程碑建议

- **M1（当前）**：项目 → 会话 → 对话，审批、面板、首启引导 ✅
- **M2**：命令面板、右键菜单、上下文进度条、全权模式二次确认
- **M3**：多标签会话（并行任务）、任务栏徽标、diff 逐行评论回传 Agent
- **M4**：插件/预设市场、团队共享预设、导出会话为 Markdown/补丁

---

> 设计价值主张：把"我信任一个会改我代码的 AI"这件事，拆解成**看得见的过程 + 收得住的安全阀 + 追得回的账本**，让授权与掌控同时成立。
