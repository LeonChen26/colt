本次设计要点
  • 只读的状态条：上下文占用条 · 成本 · 心跳（已耗时 + 最后活动）。每秒走字，超 30s 无活动转琥珀并提示“似乎卡住了”——不伪造活动，如实告知。
  • 右栏默认「正在处理」，常驻可折叠：本地文件投影（agent 正在读/改什么），是自用场景下最需要随时看到的信息。可折叠为 44px 图标条（不占地方但仍在），切到「浏览器」时才真正加载页面，在此之前不占资源。
  • 工具卡（会话流最高频）：默认折叠一行（语义图标 + 工具名 + 路径/命令 + 增删 + 耗时 + 状态），展开看 diff / 参数 / 输出。图标按工具类型区分，不统一用扳手。
  • 三列可拖拽：两条分隔线均可拖拽；双击把手复位。右栏下限 360、中栏下限 420。
  • 窄栏不溢出：输入区工具行按中栏宽度响应（容器查询）——窄时先折叠文字标签，再让右侧控制组换行独占一行，发送按钮永不逐出。
  • 浏览器内嵌停靠：由独立弹窗改为右侧一列，agent 操作与页面在同一视野，消除视线跳跃。
  • 双态切换：右上角「停靠 / 弹出」——需要大屏时用户自己弹出去，形态权交给用户。
  • agent 操作高亮：点击处涟漪环 + [e7] button「登录」 标签，把「它在点哪儿」变成看得见。
  • 观测并入面板：console / 网络 / 下载收进底部抽屉，随窗口走，不再随关窗蒸发。
  • 不抢焦：agent 的动作只更新本条提示带与高亮，不改动用户正在读的会话流。
