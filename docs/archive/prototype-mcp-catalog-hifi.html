卸载 CodeWiki？

只从 ~/.colt/mcp.json 里删掉这一条（对全部项目生效）。运行时留着——再装是秒级。

为什么这里不用原生确认框。安装用原生框是对的：那是「首次写用户级配置」这种范围大、后果不可见的事，用系统对话框更容易被认真读一遍。卸载是回收自己刚写的那一条、可逆，而且需要用户当场做一个带成本信息的选择（61MB 要不要一起清）——原生框放不下 checkbox，只能拆成两问。 顺带修一个真 bug：现在的 purgeRuntime 是设置页级的 state，勾一次会影响所有卡片的卸载文案。挪进卡内即消失。
