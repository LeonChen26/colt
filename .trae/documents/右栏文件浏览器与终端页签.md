# 右栏工作区新增「文件」浏览器与「终端」页签

## Context

用户要求在右侧边栏（⑦）集成文件浏览器和 Windows Terminal。`docs/NEXT-PHASE.md` 已有记录：终端视图需要 PTY host 能力（别照菜单补页面）、整项目树「等有人真的需要」——现在需求明确，正式排期。用户已确认方向：**嵌入交互终端**（xterm.js + node-pty/ConPTY，VS Code 同款）与**只读文件浏览器**（浏览 + 预览，不做写操作）。两个功能独立交付、分开提交。

## 两个关键设计决策

**1. PTY 生命周期锚在主进程，不锚渲染层组件。** `WorkspaceDock` 渲染分支是三元链，切页签即卸载面板——卸载即杀会丢终端会话（与 worker「切走不杀」语义冲突）；StrictMode 双挂载也会误杀。收口三层：①页签 × 关闭 → `terminal.close`；②会话 dispose（`hostBridge.disposeSession`）→ 清理；③app 退出 → `disposeAll` 兜底。切页签/切会话期间保留 64KB 环形输出缓冲，重开页签时回放（`terminal.open` 幂等复用）。

**2. 通道名 `file.list`**（非 fs.list）：与 `file.read`/`file.netDiff` 同域，边界同一套（sessionId → 项目根）。

## 第 0 步：node-pty 可行性验证（先于一切）

最大风险：原生模块在 Electron 44 ABI + 本机 SAC 下的装载。失败则只交付阶段 A。

1. `npm install @homebridge/node-pty-prebuilt-multiarch --save`（prebuilt 机制）
2. 若 ABI 不匹配：`cd node_modules/@homebridge/node-pty-prebuilt-multiarch && npx prebuild-install --runtime=electron --target=<electron 精确版本>`
3. 探针脚本 `scripts/probe-pty.cjs`（仿 probe-runtime.cjs）：require → spawn cmd.exe echo → 收输出退出。跑法 `npx electron scripts/probe-pty.cjs`，注意 unset `ELECTRON_RUN_AS_NODE`/`NODE_OPTIONS`（置空不算清掉）。
4. 降级阶梯：homebridge 预编译 → 官方 node-pty + electron-rebuild（需 VS Build Tools，SAC 拦截风险最高）→ 管道方案（明说局限：非交互，仅保底）。
5. 结论（装了哪个包/哪条命令/SAC 实测）落 `docs/NEXT-PHASE.md`，作为升 Electron 时的复验清单。

## 阶段 A：文件浏览器

### A1. 协议（`src/shared/protocol.ts`）

`IPC_CHANNELS` + `IpcInvokeMap` 加（紧挨 file.read，L854 附近）：

```ts
"file.list": {
  request: { sessionId: string; path: string };  // "" = 项目根
  response: { entries: FsEntry[]; truncated: boolean; hidden: string[] };
};
interface FsEntry { name: string; path: string; kind: "dir" | "file"; size: number; }
```

越界/不存在/非目录/权限不足走 invoke reject（同 file.read 错误通道）。`hidden` 返回被隐藏的目录名（`.git`、`node_modules`），UI 如实标注不静默吞；单层 500 条上限，`truncated` 如实说。

### A2. 主进程（新文件 `src/main/file-list.ts`，纯 Node 可单测）

`listDirWithin(root, requestedPath)`：三重校验逐条对照 `src/main/file-read.ts`（字符串级 isWithinRoot 先于 fs → realpathSync 再判一次 → statSync 是目录）；`readdirSync({withFileTypes:true})`，symlink 单独 stat 定 kind，竞态中被删的条目静默跳过；排序目录优先 + `localeCompare(…, {numeric:true, sensitivity:"base"})`（Windows 资源管理器惯例）；EACCES/EPERM 转可读中文。

接线（`src/main/ipc/index.ts` L764 file.read 旁）：`handle("file.list", …)` 一段。`tests/contract.test.ts` 自动守卫注册↔声明对齐。

### A3. 渲染层（新文件 `.../panels/FilesPanel.tsx`）

- 布局左右分栏：左树 `w-[220px] shrink-0 border-r`（极窄栏横向滚动兜底），右 `flex-1 min-w-0` 放**现成的 `FilePreview`**（接口 `{sessionId, path, reloadToken, onReload}` 正好对上，零改动）。
- 树形懒加载：`Map<path, FsEntry[]>` 缓存 + `Set` 展开态 + `selected`；点目录无缓存则拉、点文件设 selected；缩进 `depth * 12 + 8`；图标 lucide `Folder`/`FolderOpen`/`File`。
- 外壳 `SidePanelShell`（title「文件」、meta「已隐藏 .git · node_modules」、onRefresh 清缓存重拉）；单层失败在该目录节点下渲染错误+重试（agent 正在删文件是常态，别整树报错）。
- 冒烟锚点：`data-files-tree` / `data-file-entry={path}`。

### A4. 接线（`WorkspaceDock.tsx` 约 6 行）

`DockKind` 加 `"files"`（L60）；`DOCK_KIND_META` 加 `{label:"文件", Icon: FolderTree, closable: true, desc:"浏览项目内的文件"}`；渲染分支加 case（L783 链）。**不动 `Conversation/index.tsx`**——「+」菜单/折叠图标条/页签管理全由 META 推导自动生效。

### A5. 测试与文档

- 单测 `tests/file-list.test.ts`：排序（大小写/数字序）、hidden 过滤+如实返回、500 截断、越界（夹具法照抄 tests/file-read.test.ts，含软链接逃逸）、错误可读性。

## 阶段 B：终端

### B1. 协议

`IPC_CHANNELS` 加 4 条 invoke + `IPC_EVENTS` 加 2 条 event：

```ts
"terminal.open":    { req: {sessionId, cols, rows}; res: {shell, replay, nextSeq} };  // 幂等
"terminal.input":   { req: {sessionId, data}; res: {ok:true} };
"terminal.resize":  { req: {sessionId, cols, rows}; res: {ok:true} };
"terminal.close":   { req: {sessionId}; res: {ok:true} };  // 幂等
// events
"terminal.output": { sessionId, seq, data };  // 16ms 合帧批量推送
"terminal.exit":   { sessionId, code };
```

**seq 解决订阅/open 竞态**：先 `on("terminal.output")` 再 invoke open，返回 `{replay, nextSeq}` 后 write(replay)，丢弃事件中 `seq < nextSeq` 的旧帧。seq 过滤是纯函数，单测覆盖。

### B2. 主进程（新文件 `src/main/terminal-pty.ts` + `src/main/terminal-host.ts`）

**terminal-pty.ts（原生模块隔离层）**：惰性 require，失败返回可读错误（「终端不可用：原生模块加载失败」）不崩主进程；`pickShell(candidates)` 纯函数（pwsh.exe → powershell.exe → cmd.exe，注入 exists 可单测）；`buildPtyOptions(cwd, env, cols, rows)` 纯函数（`TERM=xterm-256color`）。

**terminal-host.ts（仿 browser-host.ts 的 class 组织）**：

```ts
class TerminalHost {
  open(sessionId, root, cols, rows)   // 幂等复用；cwd = resolveSessionRoot(sessionId)
  write / resize / close(sessionId)   // close: pty.kill() + 清登记；onExit 走同一清理
  isAlive(sessionId)                  // 冒烟主进程侧真源（同 View.getVisible() 先例）
  attachWindow(win); disposeAll()
}
```

输出链：`pty.onData` → pending → **16ms timer flush** 一次 `webContents.send`（把逐字符回显压到每帧一次 IPC），同时无条件追加 64KB 环形缓冲（切页签期间的输出靠它回来）。

接线三处（每处一至三行）：
1. `src/main/host/index.ts`：HostBridge 持有 terminalHost；`attachWindow` 转发；**`disposeSession` 加一行 close**（worker 回收/会话关闭自动收口）；`disposeAll` 加一行。
2. `src/main/ipc/index.ts`：4 个 handler 一行转发。
3. 不动 session-manager——terminal 是纯流，自持 window 直发。

### B3. 渲染层（新文件 `.../panels/TerminalPanel.tsx`）

依赖：`@xterm/xterm` + `@xterm/addon-fit`（**devDependencies**，bundle 进 renderer，react 先例）；CSS 顶部 `import "@xterm/xterm/css/xterm.css"`。

初始化序列（useEffect, 依赖 `[sessionId]`）：
1. `new Terminal({fontSize: 对齐 CodeView 字号档, fontFamily: --font-mono 字面量副本（注释注明与 styles.css 同一份清单）, scrollback: 2000, theme: 读 CSS 变量映射})`（已知局限写注释：主题切换不实时跟随）。
2. **先订阅** output/exit（on 返回取消函数），output 回调做 seq 过滤后 write。
3. `invoke("terminal.open", {cols:80, rows:24})` → write(replay)。
4. FitAddon + ResizeObserver：fit 后**先本地 resize 再 invoke terminal.resize**（PTY 不知道尺寸换行必错位）。
5. `term.onData → invoke("terminal.input")`。
6. exit 事件 → 「已退出（代码 N）」+ 重新打开按钮。
7. 清理：取消订阅 + dispose + disconnect。**不发 terminal.close**（生命周期锚主进程）。

外壳 SidePanelShell（meta 显示 shell 名，onRefresh = clear 清屏）；点击容器 `term.focus()`。

### B4. 接线（比 A 多一处收口）

1. `WorkspaceDock.tsx` 同 A4：`DockKind` 加 `"terminal"`，META `{label:"终端", Icon: SquareTerminal, closable:true, desc:"项目根目录的交互式终端（PowerShell）"}`，渲染分支 case。
2. `Conversation/index.tsx` 的 `closeDockInstance`（L290）加**一行**：terminal kind 时 `invoke("terminal.close", {sessionId})`——页签 × 是用户显式收口。

### B5. 测试与文档

- 单测：`tests/terminal-pty.test.ts`（pickShell 四组合、buildPtyOptions）；`tests/terminal-feed.test.ts`（seq 过滤、16ms 合帧纯函数）。不 spawn 真 PTY（冒烟的活）。
- dock 冒烟（**命令全部无副作用**，只 echo）：
  1. 开页签 → `.xterm` + `.xterm-helper-textarea` 存在；
  2. 真实输入链路：向 `.xterm-helper-textarea` 派发 KeyboardEvent（echo COLT_PTY_SMOKE + Enter，先 sleep 确认监听已挂）；
  3. **轮询** `.xterm` textContent 出现输出（固定 sleep 必假红）；
  4. **PTY 真死**：关页签 → 轮询主进程 `terminalHost.isAlive() === false`；重开 → isAlive 回 true、两次 open 同一 shell（幂等）；
  5. 切页签不杀：写一句话 → 切「统计」→ 切回 → 话还在（缓冲回放证据）；
  6. `pwd` 输出含夹具项目根（防开在仓库根）。
- 文档：UI-REGIONS.md v1.78；NEXT-PHASE.md L129 改已实施 + 第 0 步依赖结论；ARCHITECTURE.md 资源表（每会话 1 个 PTY、64KB 缓冲、16ms 合帧）；**SECURITY.md 加一条：终端是用户直操作能力面（同浏览器 B1），不走审批、模型工具面零入口——将来接给 agent 必须作为工具过 before_tool 闸门**；CONTRIBUTING.md 代码地图加新文件。
